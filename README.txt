QUÊTE DU VIVANT — PORTFOLIO SBI4U

OUVRIR DANS VISUAL STUDIO CODE
1. Décompressez le dossier Portfolio_SBI4U.
2. Ouvrez VS Code.
3. Choisissez File > Open Folder (Fichier > Ouvrir le dossier).
4. Sélectionnez le dossier Portfolio_SBI4U, pas un fichier HTML isolé.
5. Ouvrez index.html pour commencer.

APERÇU LOCAL
- Vous pouvez ouvrir index.html directement dans un navigateur.
- Pour un aperçu avec rechargement automatique, installez l'extension Live Server dans VS Code,
  puis faites un clic droit sur index.html > Open with Live Server.

PUBLIER SUR GITHUB PAGES
- Créez un dépôt GitHub.
- Téléversez le contenu de ce dossier à la racine du dépôt (index.html doit être à la racine).
- Dans Settings > Pages, choisissez Deploy from a branch, puis main et /(root).

CONTENU
- index.html : camp de départ et carte des mondes
- presentation.html : briefing d’expédition
- lettre-ouverture.html : lettre de bord
- parcours-rho.html : profil, progression, missions et insignes de Rho
- unite1.html et unite2.html : unités 1 et 2
- unite1.html : leçons du Module 1 (sections 1.1 à 2.2) et simulation enzymatique
- unite2.html : leçons du Module 2 (sections 3.1 à 4.2), respiration et photosynthèse
- articles.html : archives scientifiques sur Maud L. Menten et Norman P. A. Hüner, schémas interactifs et défis
- carrieres.html : voies d’avenir en biologie
- bibliographie.html : bibliothèque de terrain
- site.css : composants et interactions partagés du portfolio
- unite1.js : simulation pédagogique des facteurs qui influencent l’activité enzymatique
- adventure.css : mondes illustrés, interface de jeu et styles du compagnon
- adventure.js : compagnon Rho, missions, XP, insignes, audio facultatif et sauvegarde locale
- assets/rho-guide.png : illustration du rhinocéros fournie par Charlotte
- assets/rho-xp-chime.wav : son original de récompense joué quand Rho gagne des XP
- assets/maud-menten.jpg : portrait de la Smithsonian Institution Archives, via Wikimedia Commons
- assets/norman-huner.png : portrait fourni par Charlotte
- assets/world-cell.svg et assets/world-energy.svg : décors des mondes 1 et 2

Les pages restent séparées pour la compatibilité avec GitHub Pages. La progression et la préférence sonore sont sauvegardées dans le stockage local du navigateur. La musique et les effets s’activent avec le bouton près de Rho; aucun son ne démarre automatiquement. La mission finale de l’unité 1 déverrouille le monde 2; les mondes 3 à 5 restent visibles, verrouillés et sans contenu ajouté.
